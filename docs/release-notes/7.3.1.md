# 7.3.1

User-visible behavior changes. `CHANGELOG.md` carries the full merged pull request and issue list.

## Decimal field values

- A `decimal` in a field table, such as a message header, a queue or consumer argument, or `ConnectionFactory.ClientProperties`, whose unscaled value is 2147483648 to 4294967295 in magnitude, positive or negative and at any scale, is now rejected with `WireFormattingException`, as larger ones already were; for `ClientProperties`, `CreateConnectionAsync` throws `BrokerUnreachableException` wrapping it. Such a value used to be sent with its top bit dropped, so `2147483649m` arrived as `1` (#2179).

# 7.3.1

User-visible behavior changes. `CHANGELOG.md` carries the full merged pull request and issue list.

## Copying an endpoint

- `AmqpTcpEndpoint.Clone()` and `CloneWithHostname()` keep the original's `AddressFamily`. The copy used to get `ConnectionFactory.DefaultAddressFamily`, so an endpoint forced to IPv4 or IPv6 could connect over the other family once copied, for example by a custom `IEndpointResolver` that calls `CloneWithHostname` for each resolved address. A copy therefore no longer picks up a `ConnectionFactory.DefaultAddressFamily` set after the original was created; set it first, or set `AddressFamily` on the endpoint (#2127).

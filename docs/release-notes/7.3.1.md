# 7.3.1

User-visible behavior changes. `CHANGELOG.md` carries the full merged pull request and issue list.

## Assigning an endpoint to a factory

- Assigning an `AmqpTcpEndpoint` without a port to `ConnectionFactory.Endpoint` resets the factory's port, so it follows the factory's TLS setting as when only `HostName` is set: 5671 with TLS and 5672 without. `ConnectionFactory.Port` then reads -1; `Endpoint.Port` gives the port dialed. Turning the factory's TLS on after the assignment used to dial 5672, and turning it off after an endpoint with its own TLS sent plain AMQP to 5671 (#2175).

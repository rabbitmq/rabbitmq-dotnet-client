# 7.3.1

User-visible behavior changes. `CHANGELOG.md` carries the full merged pull request and issue list.

## Assigning an endpoint to a factory

- Assigning an `AmqpTcpEndpoint` without a port to `ConnectionFactory.Endpoint` leaves the factory's port unset, so it follows the factory's TLS setting as when only `HostName` is set: 5671 with TLS and 5672 without. It used to fix the port for the TLS setting at the moment of assignment, so turning the factory's TLS on afterwards dialed 5672, and turning it off after an endpoint with its own TLS sent plain AMQP to 5671 (#2175).

# 7.3.1

User-visible behavior changes. `CHANGELOG.md` carries the full merged pull request and issue list.

## A socket left open by a failed connection attempt

- With the factory's TLS off, an endpoint whose `Ssl` is `null` and that has an explicit port, or a factory with `Ssl = null` and a `Port`, connected its socket and then failed, leaving the socket open until garbage collection on every connection or recovery attempt. The attempt still fails, with `BrokerUnreachableException` wrapping a `NullReferenceException`, so give the endpoint an `SslOption`; the socket is now closed when anything fails while the frame handler is being created (#2176).

# 7.3.1

User-visible behavior changes. `CHANGELOG.md` carries the full merged pull request and issue list.

## Publishing with a null argument

- A `BasicPublishAsync` call given a null `CachedString` exchange or routing key, or a null `PublicationAddress`, throws `ArgumentNullException` naming the parameter instead of `NullReferenceException`. A body owner passed to that call is now disposed before the exception; it was never disposed before (#2101). `IReadOnlyBasicProperties.ReplyToAddress` is null when `ReplyTo` is a bare queue name, so an RPC server that publishes its replies to it hits this.
- The `IChannelExtensions.BasicPublishAsync` overloads do the same for a null `channel`: they dispose a body owner they were given and throw `ArgumentNullException` (#2170).

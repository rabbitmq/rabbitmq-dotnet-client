# 7.3.1

User-visible behavior changes. `CHANGELOG.md` carries the full merged pull request and issue list.

## Assigning an endpoint to a factory

- Assigning `ConnectionFactory.Endpoint` replaces the factory's `MaxInboundMessageBodySize` only when the endpoint was given a limit, by the `AmqpTcpEndpoint` constructor that takes one or by being read from a factory's `Endpoint`. An endpoint built without one carries the 64 MiB default, which used to replace the factory's limit, lower or higher. The factory's limit is now kept, unless it is 0, so a delivery larger than it closes the connection where 7.3.0 accepted it; raise `MaxInboundMessageBodySize` if such deliveries are expected (#2129).

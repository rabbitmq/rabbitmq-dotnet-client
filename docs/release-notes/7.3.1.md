# 7.3.1

User-visible behavior changes. `CHANGELOG.md` carries the full merged pull request and issue list.

## Recovering bindings made with arguments

- Unbinding a queue or exchange that was bound with arguments now removes the binding from the recorded topology, so automatic recovery no longer binds it again. Arguments match by content, in any key order, as on the broker, so repeating a bind with equal arguments no longer adds a binding for recovery to replay (#2147).

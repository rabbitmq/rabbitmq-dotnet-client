# 7.4.0

User-visible behavior changes. `CHANGELOG.md` carries the full merged pull request and issue list.

## Header values

- A field table value, such as a message header passed to `BasicPublishAsync`, can now be a `ReadOnlyMemory<byte>`, `Memory<byte>` or `ArraySegment<byte>` (#2144). It is sent as a long string, like a `byte[]`, so a header held in part of a reusable buffer no longer needs copying into its own array. The buffer must not change until the publish completes. These types previously threw `WireFormattingException`.

# 7.3.1

User-visible behavior changes. `CHANGELOG.md` carries the full merged pull request and issue list.

## Connection tracing

- With a listener sampling the `RabbitMQ.Client.Connection` activity source, a `null` endpoint, or one with a `null` `Ssl` and no port, ended the whole connection attempt or recovery pass whenever it was tried before a reachable endpoint: `CreateConnectionAsync` threw `BrokerUnreachableException` wrapping a `NullReferenceException`, and recovery raised `ConnectionRecoveryErrorAsync` with it. That endpoint now fails only its own `tcp connection attempt` span and the next one is tried, as without a listener (#2132).
